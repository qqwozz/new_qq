# Деплой: Как это работает

## Коротко

Пуш в `main` = сайт обновился. Всё.

## Длинно

### Автоматический деплой (рекомендуется)

1. Закоммить изменения в `feature/*` ветку
2. Замержить в `main`
3. GitHub Actions подхватит, соберёт и задеплоит автоматически
4. Через 1-2 минуты сайт обновится на `qqwozz.github.io/new_qq/`

```
git checkout main
git merge feature/resume-polish
git push origin main
```

Готово. Ничего больше делать не нужно.

### Ручной деплой (если нужно срочно)

```bash
npm run build    # собрать
npm run deploy   # задеплоить через gh-pages
```

### Проверить что деплой прошёл

Открой https://github.com/qqwozz/new_qq/actions — там видно статус каждого деплоя.
Или просто обнови https://qqwozz.github.io/new_qq/ с кэшированием (Ctrl+Shift+R).

## Часто задаваемые вопросы

**Закрыл терминал — сайт работает?**
Да. Сайт живёт на серверах GitHub, а не на твоём компьютере.

**Выключил компьютер — сайт работает?**
Да. Та же причина.

**Удалил репозиторий — сайт работает?**
Нет. Тогда и GitHub Pages пропадёт.

**Как посмотреть свой сайт до деплоя?**
```bash
npm run dev       # горячая перезагрузка на localhost:5173
npm run build && npm run preview  # превью продакшн-билда
```

**Что если деплой упал?**
Проверь GitHub Actions: https://github.com/qqwozz/new_qq/actions
Обычно ошибка в `npm run build` — посмотри логи, исправь, запушь снова.

**Как отключить сайт временно?**
Settings → Pages → Source → выбери "None". Сайт пропадёт, код останется.

**Как сменить домен?**
В `vite.config.ts` поменяй `base`. В `index.html` обнови canonical URL и OG-теги.
