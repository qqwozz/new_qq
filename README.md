# 🚀 Резюме-сайт: Документация для Хакеров

Привет! Это не boring корпоративная документация. Здесь ты найдешь все, что нужно, чтобы поднять этот проект, поиграться с ним и залить на продакшн. Проект — React 18 + TypeScript + Vite, деплойится на GitHub Pages. Все на русском, потому что сайт по умолчанию говорит на русском.

## 🛠️ Как запустить локально

1. **Клонируй репозиторий** (если еще не сделал):
   ```bash
   git clone https://github.com/qqwozz/new_qq.git
   cd new_qq
   ```

2. **Установи зависимости**:
   ```bash
   npm install
   ```

3. **Запусти dev-сервер**:
   ```bash
   npm run dev
   ```
   Вуаля! Открой браузер и перейди по адресу, который выведет Vite (обычно `http://localhost:5173`). Теперь можешь тыкать в код, а изменения будут подхватываться мгновенно.

## 📦 Как собрать и задеплоить

### Сборка
Чтобы создать продакшн-билд:
```bash
npm run build
```
Это скомпилирует TypeScript и соберет оптимизированный бандл в папку `dist/`.

### Деплой на GitHub Pages
У тебя есть два способа:

1. **Через npm-скрипт** (ручной деплой):
   ```bash
   npm run deploy
   ```
   Этот скрипт использует `gh-pages` для отправки содержимого `dist/` в ветку `gh-pages` репозитория.

2. **Через GitHub Actions** (автоматический деплой):
   У проекта уже есть файл `.github/workflows/deploy.yml`, который автоматически деплоит сайт при пуше в ветку `main`. Просто запушь изменения в `main`, и через пару минут сайт обновится.

## 🌿 Git-workflow: Как коммитить и деплоить

### Конвенции по коммитам
Мы не строгие, но рекомендуем использовать осмысленные сообщения. Примеры:
- `feat: добавил секцию Languages`
- `fix: исправил баг с языковым переключателем`
- `style: обновил стили для секции Contact`
- `docs: обновил README`

### Процесс деплоя
- **Автоматический**: Просто запуши изменения в ветку `main`. GitHub Actions подхватит и задеплоит.
- **Ручной**: Если хочешь задеплоить вручную, выполни `npm run deploy` (убедись, что билд актуален).

### Ветки
- `main` — основная ветка, отсюда деплоится продакшн.
- `feature/*` — для новой функциональности. После мержа в `main` деплой произойдет автоматически.

## ✏️ Как добавлять и менять контент

### Основной компонент
Весь контент живет в `src/App.tsx`. Это один компонент, который разбит на секции:
- **Hero** — приветствие и основная информация.
- **Skills** — навыки.
- **Experience** — опыт работы.
- **Projects** — проекты.
- **Languages** — языки.
- **Contact** — контакты.

### Языковое переключение
Переключатель RU/EN реализован через состояние React. Тексты хранятся в объекте `t` внутри компонента. Чтобы изменить текст:
1. Открой `src/App.tsx`.
2. Найди объект `t` с ключами `ru` и `en`.
3. Отредактируй нужные строки.

Пример:
```typescript
const t: Record<Lang, Record<string, string>> = {
  ru: {
    name: 'Дима Киселев',
    role: 'Backend-разработчик',
    // ...
  },
  en: {
    name: 'Dima Kiselev',
    role: 'Backend Developer',
    // ...
  },
}
```

### Стили
Все стили в `src/styles.css`. Если хочешь поменять цвета, шрифты или отступы — редактируй этот файл.

### Добавление новой секции
1. В `App.tsx` добавь новую секцию в JSX (например, `<section id="new-section">`).
2. Добавь соответствующий текст в объекты `textsRu` и `textsEn`.
3. Не забудь обновить навигацию, если нужно.

## 🎨 Кастомизация

- **Цвета**: Измени CSS-переменные в `:root` в `styles.css`.
- **Шрифты**: Подключи другие шрифты через Google Fonts в `index.html`.
- **Контент**: Все в `App.tsx` — просто правь тексты.

## 🐛 Если что-то пошло не уилось

1. **Ошибки при запуске**: Убедись, что установил все зависимости (`npm install`).
2. **Ошибки TypeScript**: Проверь типы в `App.tsx` — возможно, пропустил какое-то поле.
3. **Деплой не работает**: Проверь, что в `vite.config.ts` базовый путь совпадает с названием репозитория (`/new_qq/`).
4. **GitHub Actions не запускается**: Убедись, что workflow файл в правильном месте и ветка `main` активна.
